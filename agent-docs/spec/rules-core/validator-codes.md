# Validator codes

## 5.2 Validator codes

HARD: `WEIGHT_CAP_EXCEEDED`, `VOLUME_CAP_EXCEEDED`, `REEFER_REQUIRED`, `VAN_REQUIRED`, `DEPOT_MISMATCH`, `MIXED_BRAND`, `MIXED_DISTRICT`, `ORDER_SPLIT`, `ORDER_UNASSIGNED_UNKNOWN`, `TRIP_LIMIT_EXCEEDED`, `TIME_BUDGET_EXCEEDED`, `WINDOW_MISSED`, `MALL_WINDOW_VIOLATION`, `NON_OPERATING_DAY`, `FUEL_QUOTA_EXCEEDED`, `VEHICLE_UNAVAILABLE`, `ORDER_NOT_CONFIRMED`.
WARN: `LATE_RISK`, `REPEAT_DEFERRAL`, `LOW_FUEL_MARGIN`.
