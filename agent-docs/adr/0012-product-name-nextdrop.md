# ADR 0012: Product name is NextDrop

- Status: accepted
- Date: 2026-10-02
- Issue / PR: owner decision (Dinura), see the PR that adds this file
- Designathon departure: yes (label `designathon-departure`)

## Context

The design uses 'Waypoint' for the product. The repository is called NextDrop.

## Decision

The product is **NextDrop**. Waypoint Group remains the customer and Waypoint Fresh a brand name in the data. User-facing product strings, the README and the package name use NextDrop.

## Alternatives considered

- Waypoint as the product name: matches the frames but not the repository or the owner's choice.

## Consequences

Figma frames still show 'Waypoint' until refreshed (departure). Edited: `AGENTS.md`, `package.json`, `spec/README.md`, `spec/overview.md`.
