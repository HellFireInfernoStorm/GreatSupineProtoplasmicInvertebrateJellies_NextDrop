# agent-docs

Context for developers and agents. The submission folder `docs/` is separate and holds only the architecture diagram, data model and AI disclosure.

Read the root [AGENTS.md](../AGENTS.md) first. It gives the precedence rule, commands and boundaries.

| Directory | Holds |
| --- | --- |
| [brief/](brief/README.md) | The Challenge Booklet (unchanged) and the requirements-to-architecture map |
| [spec/](spec/README.md) | How the system is built, split by concern. Starts as draft |
| [design/](design/README.md) | Day 5 Figma design context: screens, tokens, status language, mock story |
| [adr/](adr/0000-template.md) | Architecture decision records and recorded departures |
| [process/](process/start-task.md) | How to start a task, reach GitHub, write PRs and commits, change the spec, avoid collisions, git hooks |
